## Shared patterns
- Desktop views use a left navigation rail with Overview, Task, Mentors, Message and Settings, plus notification/profile affordances; mobile views replace the rail with a menu icon. This is visible across `render-web---dashboard-6-2335`, `render-web---task-36-3071`, `render-web---detail-task-39-1865`, `render-web---mentors-36-5489`, `render-web---message-38-2152`, `render-web---settings---general-53-3034` and their mobile counterparts.
- Task catalogue cards consistently combine an image, name/category, progress indicator and time information; dashboard upcoming-task cards repeat this pattern (`render-web---task-36-3071`, `render-mobile---task-36-4048`, `render-web---dashboard-6-2335`, `render-mobile---dashboard-36-3066`).
- Settings use General and Notification tabs with Save Changes; the category switches shown are Message, Task Update, Task Deadline and Mentor Help (`render-web---settings---general-53-3034`, `render-web---settings---notification-58-2195`, `render-mobile---settings---general-55-2018`, `render-mobile---settings---notification-58-2279`).
- Mentor profiles use Follow/Followed state and public-looking task/rating metrics (`render-web---mentors-36-5489`, `render-mobile---mentors-36-6747`).
- Messaging separates a contact list from the selected chat on desktop; mobile shows the contact list and chat as separate renders. The matching pair is `render-web---message-38-2152` plus `render-mobile---message-53-2129` and `render-mobile---message---chat-53-2749`; the same organization recurs in the design-area renders.
- The render set contains wireframe placeholders, high-fidelity screens and alternate design-area screens. They repeat major page families but vary in populated content, dates and branding (`render-web---dashboard-84-2544`, `render-web---dashboard-6-2335`, `render-web---dashboard-133-7928`).

## Open questions
- The task catalogue is titled “Explore Task” and contains sample design/development tasks, while the product requirement describes assigned educational activities. Should these screens be repurposed to list only the learner’s assigned activities, and should the “Explore” framing and task-category controls remain? Relevant evidence: `render-web---task-36-3071`, `render-mobile---task-36-4048`, `render-web---task-133-8347`.
- The detail screen provides a file drop/browser control and a generic “Submit” button, but shows no “Start”, “Submit for review”, correction/resubmit action, submission-version history, late indicator, confirmation/error feedback, or completed/locked state. Where should each action and feedback appear, and what should the student see after a successful or failed submission? Relevant evidence: `render-web---detail-task-39-1865`, `render-mobile---detail-task-84-2102`, `render-web---detail-task-133-8634`.
- The “Essence of Assessment” checklist reads as learning outcomes, not an evaluation panel. No mentor review controls, version selection, completion action, correction-reason field or reviewed status is depicted. Is the checklist intended as student-facing criteria, and where should the assigned mentor perform and communicate a version-specific review? Relevant evidence: `render-web---detail-task-39-1865`, `render-web---detail-task-133-8634`.
- The detail’s “Assigned Assignments” section includes student identity and submission controls, but the screen has no explicit role indicator and a “Submit” action. Is this a learner’s own assignment or a mentor view of an assigned student? Which details/actions should differ by role? Relevant evidence: `render-web---detail-task-39-1865`, `render-mobile---detail-task-84-2102`.
- Dashboard “Running Task”, 45%/100 Task, weekly activity, progress sliders and calendar/task panel do not define the required task lifecycle counts, completion-only progress, authorization scope, date range or synchronized filters. Which metrics and ranges should be shown, and how should they align with the task list? Relevant evidence: `render-web---dashboard-6-2335`, `render-mobile---dashboard-36-3066`, `render-web---dashboard-133-7928`.
- Mentor directory cards expose Follow/Followed, task totals and review ratings, but no assignment relationship or student-task access boundary. Should Follow mean communication preference only, and how should the assigned mentor be identified without granting access to other students’ work? Relevant evidence: `render-web---mentors-36-5489`, `render-mobile---mentors-36-6747`.
- Conversation rows use red dots and blue double-check marks, while a bell icon has a red badge; no notification inbox or notification-read state is rendered. What do the row markers mean, and where/how are in-app notifications individually read without marking a conversation read? Relevant evidence: `render-web---message-38-2152`, `render-mobile---message-53-2129`, `render-mobile---message---chat-53-2749`, `render-web---dashboard-6-2335`.
- Notification settings show four category switches but do not label them as email or in-app controls. Which categories govern email, and how should the always-on in-app notifications be represented while preserving the independent email preference? Relevant evidence: `render-web---settings---notification-58-2195`, `render-mobile---settings---notification-58-2279`.
- Desktop and mobile layouts preserve broadly similar page content, but no renders show narrow-screen states for upload errors, status/late feedback, review actions or notifications. What is the intended placement and feedback for those required flows on each form factor? Relevant evidence: `render-web---detail-task-39-1865`, `render-mobile---detail-task-84-2102`, `render-web---settings---notification-58-2195`, `render-mobile---settings---notification-58-2279`.
- Several near-duplicate high-fidelity/design-area frames use different names, years and sample dates (including DNX/Nuegas and 2022/2024). Which screen variant is the visual source of truth for implementation? Relevant evidence: `render-web---dashboard-6-2335`, `render-web---dashboard-133-4811`, `render-web---dashboard-133-7928`, `render-web---detail-task-39-1865`, `render-web---detail-task-133-8634`.
